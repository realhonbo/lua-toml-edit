# lua-toml-edit 0.2.7-1

Initial release for LuaRocks.

A Lua binding to Rust's `toml_edit` for parsing and editing TOML while preserving
surrounding formatting, comments, and key order. Supports reading, setting, and
removing values using dotted paths or path arrays.

- Package: `lua-toml-edit`
- Module: `toml_edit`
- Lua: 5.1–5.4 and LuaJIT
- Build requirements: Rust/Cargo and `luarocks-build-rust-mlua`
